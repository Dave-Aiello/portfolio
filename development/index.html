Development

I also build what I design. First are three projects people use today, then smaller pieces, including two demos you can try on this site.

Magic Dragon dispatch board

Dispatchers drag orders to drivers, change the order of stops and see an ETA on every card. Changes show up on every open board right away, so two dispatchers can work at the same time.

Read the case study Real product, 2026 · React, TypeScript, HTML5 Drag and Drop

Magic Dragon storefront

The website customers order from. It has product pop-ups that handle keyboard focus properly, sign-in with a text code, and a 21+ age check that still lets search engines read the menu.

Read the case study Real product, 2026 · Next.js, CSS Modules, WCAG 2.2 AA

The Main Vine: family trees for giant pumpkins

Growers choose seeds based on a plant's family history, but the official results only list the parents as typed-in names. The site links 65,581 results into family trees you can click through, and works out inbreeding in the browser.

Read the case study Personal project, 2026 · JavaScript, Vercel Functions, Postgres
