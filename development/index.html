Development

I also build what I design. Three projects that people use, then smaller pieces, including two working demos you can try here.

Magic Dragon dispatch board: a delivery night on one screen

Dispatchers drag orders into driver lanes, reorder stops and see a real ETA on every card. Updates stream to every open board, so two dispatchers can work the same night.

Read the case study Real product, 2026 · React, TypeScript, HTML5 Drag and Drop

Magic Dragon storefront: a menu and checkout built for one hand

The web menu customers order from. Category rails, a quick view with managed focus, sign-in by text code, and a 21+ age gate that still lets search engines read the menu.

Read the case study Real product, 2026 · Next.js, CSS Modules, WCAG 2.2 AA

The Main Vine: every giant pumpkin since 2005, in one family tree

Growers pick seeds by pedigree, but weigh-off results list parents as hand-typed names. This site links 65,581 entries into family trees you can explore, with the inbreeding math done in the browser.

Read the case study Personal project, 2026 · JavaScript, Vercel Functions, Postgres
