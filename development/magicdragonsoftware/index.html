The animated board

The hero is the real board layout, drawn at a fixed design size and scaled to fit the screen. On phones it doesn't shrink to an unreadable size. It crops to the first few columns instead. A short script plays a loop of the things dispatchers actually do: a new order lands, it's dragged to a driver, it turns ready, and a delivery completes.

Cards move with the FLIP technique: measure where the card is, move it in the DOM, measure again, then animate the transform from the old position to zero. The browser does one layout and the animation runs on the compositor.

function flipTo(card, list) {
  var first = card.getBoundingClientRect();
  list.appendChild(card);
  var last = card.getBoundingClientRect();
  var s = scale();
  var dx = (first.left - last.left) / s;
  var dy = (first.top - last.top) / s;
  card.classList.add("is-flying");
  card.style.transition = "none";
  card.style.transform = "translate(" + dx + "px," + dy + "px)";
  void card.offsetWidth;
  card.style.transition = "transform 750ms cubic-bezier(0.2, 0.7, 0.2, 1)";
  card.style.transform = "";
}

The fleet map

The map is drawn with the Canvas 2D API: roads, towns, routes and cars, with each car's position computed along its route for the current time. The backing store is scaled by devicePixelRatio so lines stay sharp, a ResizeObserver redraws it when its box changes, and an IntersectionObserver stops the animation loop while it's off screen.

Motion settings and performance

  • With prefers-reduced-motion, the loops never start and the map shows a still frame.
  • Both loops wait while the tab is hidden or the demo is scrolled away.
  • No framework and no build step: one stylesheet, one script, and two web fonts.
